# 快慢指针寻找入环点的数学证明

## 第一阶段：判断是否有环

1. 定义两个指针：慢指针`slow`（每次走 1 步）快指针`fast`（每次走 2 步）
2. 如果链表存在环，当两个指针都进入环内后，`fast`相当于以相对速度1步/轮逐渐追赶`slow`，因此`fast`必然会在环内从后面追上`slow`两者重合。
3. 无环的情况：如果`fast`或`fast->next`指向了`nullptr`，说明链表到达终点无环

## 第二阶段：寻找入环点（数学推导）

      head            入环点          相遇点
      o ----- a ---->  o ----- b -----> o
                       ^                |
                       |                |
                       +------ c ------ +

### 符号定义：

- a：头节点到入环点的距离（节点间隔数）
- b：入环点到相遇点的距离
- c：相遇点再走回到入环点的距离（因此环的总长度为`b+c`）。

### 方程建立：

当slow和fast在相遇点重合时：
1. slow 走过的总路程：`a+b`(注：慢指针刚进入环的第一圈内，必然会被快指针追上)
2. fast 走过的总路程：`a+b+n(b+c)`(`n>=1`表示快指针已经在环内转了`n`圈)


因为`fast`的速度是`slow`的2倍，所以路程也是2倍：

      `2×(a+b)=a+b+n(b+c)`

化简方程：

      `a=(n-1)(b+c)+c`
      
结论分析：当`n==1`（最常见的情况）时：`a=c`这意味着：从“头节点”到“入环点”的距离`a`，正好等于从“相遇点”继续走到“入环点”的距离`c`
(如果`n>1`，含义无非是另一个指针在环里多转了`n-1`圈，最终依然会在入环点相遇)

###  操作步骤:

1. 当`fast`和`slow`相遇后，将其中一个指针重新指向`head`（头节点）
2. 保持两个指针的步长均为1步/次，两指针下一次相遇的节点即为入环点
