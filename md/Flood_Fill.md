### 一、核心认知：图与树的本质区别（图片中的核心理论点）

图片在“理论”环节明确标注了 **“图的DFS/BFS：与树遍历的区别（visited数组防环）”**：

* **树（Tree）**：是有向无环的，从根节点往下递归，子节点不会指向父节点，因此**不需要**标记访问。
* **图 / 二维网格（Graph / Grid）**：上下左右是双向相通的（存在环），如果从 $(i,j)$ 走到 $(i+1,j)$，下一步又会走回 $(i,j)$，直接陷入**无限死递归或死循环**。
* **破环手段**：必须有机制防止重复访问。**沉岛法**与 **visited 数组** 本质上就是实现“防环”的两种不同手段。

### 二、网格连通块的四大解题技巧与选型场景

#### 1. 沉岛法（In-place Sinking / Flood Fill）

* **原理**：直接将访问过的陆地原地修改为水域或新颜色（例如将 `'1'` 改为 `'0'`，或在 LC 733 中将 `oldColor` 改为 `color`）。


* **什么时候用**：
* **允许修改原数组**（最常规的面试、LeetCode、牛客/洛谷题）。


* 追求最极致的代码精简度和 $O(1)$ 辅助空间（省去 `visited` 矩阵分配）。


* **代表题目**：LC 200（求连通分量个数）、LC 695（求连通分量大小）、LC 733（图像渲染）。



#### 2. visited 数组标记法

* **原理**：额外开辟一个同等维度的 `vector<vector<bool>> visited` 或哈希集合。
* **什么时候用**：
* **题目明确要求不可修改输入**（如 `const vector<vector<char>>& grid` 或多线程只读场景）。
* 原地修改会破坏后续其他维度的状态判断时。



#### 3. 逆向思维 / 边界沉岛（变种技巧）

* **原理**：不从内部找连通块，而是先将所有**与边界相连**的陆地沉没/染色为特殊标记（如 `'#'`），再遍历整个矩阵处理剩下的“孤立/飞地”部分。
* **什么时候用**：
* 题目要求“被包围的区域”、“无法离开边缘的陆地”。


* **代表题目**：LC 130（被围绕的区域）、LC 1020（飞地的数量）。

#### 4. 并查集（Disjoint Set Union, DSU）

* **原理**：二维坐标扁平化为一维（$index = i \times n + j$），将相邻的陆地执行 `union`。
* **什么时候用**：
* **动态连通性问题**：陆地是逐步添加进来的（如 LC 305 岛屿数量 II）。
* 需要频繁查询两个坐标是否属于同一块陆地。

### 三、沉岛法与连通块问题的通用代码套路（模板）

网格连通块无论是求数量、求最大面积、还是改色，都严格遵循“外层扫描触发 + 内层 DFS 扩散沉岛”的三段式套路。

#### 统一代码模板

```cpp
class Solution {
    int m, n;
    // 方向数组（标准套路：上下左右）
    const int dx[4] = {-1, 1, 0, 0};
    const int dy[4] = {0, 0, -1, 1};

    int dfs(int i, int j, vector<vector<char>>& grid) {
        // 1. Base Case：统一越界判断 + 碰到水域/已沉岛格子直接返回
        if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] == '0') {
            return 0; // 若为求面积则返回0；仅遍历则直接 return;
        }

        // 2. 沉岛操作：防环的核心，先淹没当前格子
        grid[i][j] = '0';

        // 3. 统计自身贡献（面积为1）
        int area = 1;

        // 4. 四向扩散递归
        for (int d = 0; d < 4; ++d) {
            int ni = i + dx[d];
            int nj = j + dy[d];
            area += dfs(ni, nj, grid);
        }

        return area;
    }

public:
    int solve(vector<vector<char>>& grid) {
        if (grid.empty() || grid[0].empty()) return 0;
        m = grid.size();
        n = grid[0].size();
        int ans = 0;

        // 5. 外层全图扫描
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (grid[i][j] == '1') {
                    // 场景A (LC 200 岛屿数量)：计数器 + 1
                    ans++;
                    dfs(i, j, grid);

                    // 场景B (LC 695 最大面积)：更新最大值
                    // ans = max(ans, dfs(i, j, grid));
                }
            }
        }
        return ans;
    }
};

```

### 四、刷题避坑指南

1. **递归越界写在 Base Case**：不要在 `for` 循环内部写繁琐的 `if (ni >= 0 && ...)`，统一在 `dfs` 入口处第一行校验边界，代码最不易出错且干净。
2. **字符 `'0'` 与数字 `0` 的类型陷阱**：
* LC 200 中 `grid` 类型是 `vector<vector<char>>`（字符 `'1'` 和 `'0'`）。


* LC 695 中 `grid` 类型是 `vector<vector<int>>`（整数 `1` 和 `0`）。


* LC 733 中是带颜色的整数 `int`，若遇到起始颜色与目标颜色相同（`oldColor == newColor`），不加特判直接沉岛染色会导致无限循环。
