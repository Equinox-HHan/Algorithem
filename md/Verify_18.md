### 方法二：双指针拼接法（隐式消除长度差 / “双向奔赴”）

#### 1. 核心逻辑
这是一种极其优雅的方法，**不需要提前计算长度**，而是通过“交换跑道”在逻辑上拼接两条链表，从而抹平长度差。

*   定义指针 `pA` 指向 `headA`，指针 `pB` 指向 `headB`。
*   `pA` 遍历完链表 A 后，**重置指向链表 B 的头部**。
*   `pB` 遍历完链表 B 后，**重置指向链表 A 的头部**。

**为什么这个方法可行？**
设链表 A 独有长度为 $a$，链表 B 独有长度为 $b$，公共部分长度为 $c$：
*   `pA` 走过的总路径：$a + c + b$
*   `pB` 走过的总路径：$b + c + a$

由于 $a + c + b = b + c + a$，当两个指针都走了 $a + b + c$ 步时，**它们必将在相交点相遇**。

#### 2. 特殊情况判断（如果不相交？）
如果两条链表完全不相交（$c = 0$）：
*   `pA` 走了 $a + b$ 步后指向 `nullptr`。
*   `pB` 走了 $b + a$ 步后也指向 `nullptr`。
*   此时 `pA == pB == nullptr`，循环自然终止，返回 `nullptr`，完美兼容！

#### 3. 图解
```text
路径 1 (pA): [A 独有] -> [公共部分] -> [B 独有] -> [公共部分]
路径 2 (pB): [B 独有] -> [公共部分] -> [A 独有] -> [公共部分]
                                            ▲
                                    两指针必定在此处相遇
```

#### 4. C++ 模板代码
```cpp
ListNode* getIntersectionNode_Implicit(ListNode* headA, ListNode* headB) {
    if (!headA || !headB) return nullptr;

    ListNode *pA = headA;
    ListNode *pB = headB;

    // 当 pA == pB 时跳出循环：
    // 1. 如果相交，pA 和 pB 指向第一个公共节点
    // 2. 如果不相交，pA 和 pB 最终会同时变为 nullptr
    while (pA != pB) {
        // pA 走完 A 就去走 B，否则继续向前
        pA = (pA == nullptr) ? headB : pA->next;
        // pB 走完 B 就去走 A，否则继续向前
        pB = (pB == nullptr) ? headA : pB->next;
    }

    return pA; // 返回相交节点或 nullptr
}
```

### 两种方法的对比总结

| 维度 | 方法一：显式长度对齐法 | 方法二：双指针拼接法 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(M + N)$（需遍历两次链表） | $O(M + N)$（最多遍历两次链表） |
| **空间复杂度** | $O(1)$ | $O(1)$ |
| **代码量** | 稍长，逻辑直观 | 极其精简（核心仅 4 行） |
| **思考难度** | 容易想到（工程思维） | 技巧性强（数学逻辑） |
| **推荐场景** | 面试时用来向面试官清晰地解释逻辑 | 代码实战、追求极致简洁 |
