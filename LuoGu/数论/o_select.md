我们直接拆开代码，像剥洋葱一样一段一段看。

欧拉筛的目标就一句话：**让每一个合数，都死在它“最小的质因数”手里，绝不被多杀一次。**

---

**第一块：准备阶段**

```cpp
const int MAXN = 10000005;
bool isNotPrime[MAXN]; // 默认全为 false（代表都是质数）
int primes[MAXN];      // 用来排队装发现的质数
int cnt = 0;           // 记录发现了多少个质数

// 0 和 1 不是质数，提前踢掉
isNotPrime[0] = isNotPrime[1] = true;

```

这一步很简单：拿一个白名单 `primes` 存素数，拿一个黑名单标记 `isNotPrime`。

---

**第二块：外层巡逻**

```cpp
for (int i = 2; i <= n; i++) {
    // 如果走到 i 时它身上没被贴合数标签，那它铁定就是质数
    if (!isNotPrime[i]) {
        primes[++cnt] = i; // 把它记进质数小本本
    }
    // ... 紧接着用这个 i 去消灭合数 ...
}

```

* 如果数字 $i$ 没有被之前的人标记过，说明 2 到 $i-1$ 里面没有任何数能整除它，那它就是新的质数。

---

**第三块：内层打标（核心重头戏）**

```cpp
    for (int j = 1; j <= cnt && i * primes[j] <= n; j++) {
        // 1. primes[j] 是质数，乘以 i 得到的肯定是合数，标记掉！
        isNotPrime[i * primes[j]] = true; 

        // 2. 灵魂一刀：一旦整除了，立刻停下！
        if (i % primes[j] == 0) {
            break; 
        }
    }

```

重点就在最后这个 `break`，为什么一旦整除就要停？

假设我们现在外层巡逻到了 **$i = 4$**，这时质数表里有 `[2, 3]`：

1. 取出质数 $2$：算出来 $4 \times 2 = 8$，标记 8 是合数。
2. 此时一除：`4 % 2 == 0`，满足了！**立刻 break 退出循环**。

**如果不退出会怎样？**
如果不写 `break`，循环会去拿下一个质数 $3$：

* 它会去标记 $4 \times 3 = 12$。
* 但是，**12 的最小质因数是 2，根本不是 3！**
* 12 真正的主人是质数 2，等以后外层循环巡逻到 **$i = 6$** 时，自然会有 $6 \times 2 = 12$ 把它收割掉。
* 如果你在这里用 3 把它打上标记，12 就被重复杀了两次（一次在 $4 \times 3$，一次在 $6 \times 2$），算法就会退化变慢。

所以一句话口诀：**碰到底细（被整除），立刻收手，把后面的合数留给更小的质数去筛。**

---

**拼起来的完整体**

```cpp
void euler(int n) {
    for (int i = 2; i <= n; i++) {
        // 发现新质数
        if (!isNotPrime[i]) primes[++cnt] = i;

        // 挨个用小本本里的质数去干掉合数
        for (int j = 1; j <= cnt && i * primes[j] <= n; j++) {
            isNotPrime[i * primes[j]] = true;

            // 撞车了，说明 primes[j] 已经是 i 的因数了
            // 后面的合数轮不到更大的质数来筛，跑路！
            if (i % primes[j] == 0) break;
        }
    }
}

```
