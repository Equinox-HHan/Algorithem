洛谷 P1029［NOIP 2001 普及组］最大公约数和最小公倍数问题，核心在于利用两个数的最大公约数（$x_0$）**与**最小公倍数（$y_0$）之间的乘积关系。

---

**核心数学性质**

设要求的两个数为 $P$ 和 $Q$，且满足：

* $\gcd(P, Q) = x_0$
* $\operatorname{lcm}(P, Q) = y_0$

根据数论基本定理：


$$P \times Q = \gcd(P, Q) \times \operatorname{lcm}(P, Q) = x_0 \times y_0$$

设两数乘积 $M = x_0 \times y_0$。这说明：只要确定了 $P$，$Q$ 的值就固定为 $\frac{M}{P}$。

同时，必须满足基本的前提条件：

* $y_0$ 必须能被 $x_0$ 整除（即 $y_0 \pmod{x_0} == 0$），否则无解，直接输出 0。

---

**解题思路转化**

问题转化为：在 $M$ 的所有因数中，寻找有多少对 $(P, Q)$ 满足：

1. $P \times Q = M$
2. $\gcd(P, Q) = x_0$

**枚举优化（从 $O(M)$ 降到 $O(\sqrt{M})$）**：
因数总是成对出现的。我们只需要从 $1$ 枚举到 $\sqrt{M}$：

* 遍历 $P$（从 $1$ 到 $\lfloor\sqrt{M}\rfloor$）；
* 若 $M \pmod P == 0$，则对应的 $Q = \frac{M}{P}$；
* 检验 $\gcd(P, Q) == x_0$ 是否成立；
* 若成立：
* 若 $P \neq Q$，则 $(P, Q)$ 和 $(Q, P)$ 是两组不同的解，计数加 2；
* 若 $P == Q$，只有一组解，计数加 1。



---

**参考实现（C++）**

```cpp
#include <iostream>
#include <numeric>

using namespace std;

// 手写或使用 std::gcd
long long gcd(long long a, long long b) {
    return b == 0 ? a : gcd(b, a % b);
}

int main() {
    long long x0, y0;
    if (!(cin >> x0 >> y0)) return 0;

    // 最小公倍数必须是最大公约数的倍数
    if (y0 % x0 != 0) {
        cout << 0 << "\n";
        return 0;
    }

    long long M = x0 * y0;
    int ans = 0;

    // 枚举 P，直到 P * P > M
    for (long long P = 1; P * P <= M; P++) {
        if (M % P == 0) {
            long long Q = M / P;
            if (gcd(P, Q) == x0) {
                if (P == Q) ans += 1;
                else ans += 2; // (P, Q) 和 (Q, P) 算两组
            }
        }
    }

    cout << ans << "\n";
    return 0;
}

```

---

这种“进一步简化”的本质，是**把“求最大公约数”的问题，彻底降维成“初中分解质因数”**。

---

**第一步：先脱掉公因数的“外衣”**

已知：

* $\gcd(P, Q) = x_0$
* $\operatorname{lcm}(P, Q) = y_0$

因为 $x_0$ 是它们的最大公约数，所以 $P$ 和 $Q$ 肚子里一定都有一个 $x_0$。我们直接把它提出来：

* 设 $P = a \times x_0$
* 设 $Q = b \times x_0$

这里的 $a$ 和 $b$ 必须满足一个致命条件：**$\gcd(a, b) = 1$（$a$ 和 $b$ 必须互质）**。
如果它们还能再约分出一个 2 或 3，那最大公约数就不止是 $x_0$ 了。

代入公倍数公式：


$$\operatorname{lcm}(P, Q) = a \times b \times x_0 = y_0$$


两边同时除以 $x_0$，得到：


$$a \times b = \frac{y_0}{x_0}$$

记 $K = \frac{y_0}{x_0}$。问题瞬间变成了：**把整数 $K$ 拆成两个互质的数 $a \times b$，有多少种拆法？**

---

**第二步：为什么答案只取决于“不同质因数的个数”？**

根据算术基本定理，任何整数 $K$ 都可以拆成质因数的幂次乘积。
举个生动的例子，假设算出来 $K = 360$：


$$360 = 2^3 \times 3^2 \times 5^1$$


这里有 3 种不同的质因子：$2$、$3$ 和 $5$。

现在我们要把这堆积木打包分给 $a$ 和 $b$。
**关键规矩：相同的质因子，必须“打包打包全分给某一个人”，绝不能拆开！**

* 如果把 $2^3$ 拆开：分给 $a$ 一个 $2$，分给 $b$ 两个 $2$（即 $2^2$）。
* 这时 $a$ 和 $b$ 都会含有质因数 $2$。
* 结果就是 $\gcd(a, b) \ge 2$，它们**不再互质**，直接违规！

所以：

* 所有的 2（即 $2^3 = 8$）是一个不可分割的整体，只有两种归宿：**要么全给 $a$，要么全给 $b$**。
* 所有的 3（即 $3^2 = 9$）也是一个整体：**要么全给 $a$，要么全给 $b$**。
* 所有的 5（即 $5^1 = 5$）同理：**要么全给 $a$，要么全给 $b$**。

对于每一个不同的质因子，都只有 **2 种选择**（给 $a$ 或给 $b$）。
如果 $K$ 拥有 $m$ 个不同的质因子，根据乘法原理，总分配方案数就是：


$$2 \times 2 \times \dots \times 2 = 2^m$$

---

**第三步：算法执行全过程**

1. 算 $K = y_0 / x_0$，如果不能整除（$y_0 \pmod{x_0} \ne 0$），直接输出 0。
2. 特殊情况：如果 $K = 1$（即 $x_0 = y_0$），说明 $P=Q=x_0$，只有 $(x_0, x_0)$ 这一种答案，输出 $2^0 = 1$。
3. 从 2 开始对 $K$ 分解质因数，统计有多少个**不同**的质因子，记为 $m$。
4. 输出 $2^m$（用位运算写就是 `1 << m`）。

---

**极简代码实现（仅 $O(\sqrt{K})$，常数极小）**

```cpp
#include <iostream>

using namespace std;

int main() {
    long long x0, y0;
    if (!(cin >> x0 >> y0)) return 0;

    // 前提：y0 必须能整除 x0
    if (y0 % x0 != 0) {
        cout << 0 << "\n";
        return 0;
    }

    long long K = y0 / x0;
    int m = 0; // 记录有多少个不同的质因数

    // 经典质因数分解模板：只用枚举到 sqrt(K)
    for (long long i = 2; i * i <= K; i++) {
        if (K % i == 0) {
            m++; // 发现了一个新的质因子 i
            while (K % i == 0) {
                K /= i; // 把所有的 i 彻底除干净
            }
        }
    }
    // 如果除到最后剩下的 K 大于 1，说明它本身也是一个质数
    if (K > 1) {
        m++;
    }

    // 每个不同质因子有两个去向（给 a 或给 b），答案即 2^m
    cout << (1LL << m) << "\n";

    return 0;
}

```

**为什么这种写法极快？**
不需要枚举成千上万个因子去反复调用 `__gcd()` 计算，只要做一次质因数分解把因数除尽，直接按位移输出 $2^m$，计算步数通常在几十到几百次以内。
