# P1678 烦恼的高考志愿

## 题目描述

现有 $m$ 所学校，其中第 $i$ 所学校的预计分数线为 $a_i$。有 $n$ 位学生，其中第 $i$ 位学生的估分为 $b_i$。

根据 $n$ 位学生的估分情况，分别给每位学生推荐一所学校，要求学校的预计分数线和学生的估分相差最小（可高可低，毕竟是估分嘛），这个最小值为这位学生的不满意度。求所有学生的不满意度的和。

## 输入格式

第一行包含两个正整数 $m,n$，分别表示学校数和学生数。

第二行包含 $m$ 个非负整数 $a_1,a_2,\dots,a_m$，分别表示 $m$ 所学校的预计分数线。

第三行包含 $n$ 个非负整数 $b_1,b_2,\dots,b_n$，分别表示 $n$ 位学生的估分。

## 输出格式

输出一行一个非负整数，表示所有学生的不满意度的和。

## 说明/提示

数据范围：

对于 $30\%$ 的数据，$1\le n,m\le{10}^3$，$0\le a_i,b_i\le{10}^4$；

对于 $100\%$ 的数据，$1\le n,m\le{10}^5$，$0\le a_i,b_i\le{10}^6$。

## 思路：

为什么会想到二分查找：
1. 数据规模不支持暴力扫，每次查询时间复杂度要求在1或者对数级
    - 常数级查询通常使用哈希表：但是这道题不是精确锁定而是邻域匹配
    - 对数级查询最经典的就是 *** 有序序列上的二分查找 ***
2. 数据是一维的：如果在一维的数轴上已经有序：
    - 每一个学生的估分一定会落在某两个数之间：邻域匹配
    - 本质就是找大于等于x的第一个数和小于等于y的最后一个数 *** 二分查找经典定义 ***

### 识别这类题目的“指纹”

当你以后看到题目满足这三个特征时，第一反应就应该是**排序 + 二分**：

1. **一维数值**下的极值/距离匹配（最小差值、最接近的数）。
2. **多组独立查询**（静态数据集，多次 query）。
3. 暴力积达到 $10^{10}$，但 $O(Q \log N)$ 刚好落在 $10^6 \sim 10^7$ 黄金安全区间。

```
#include <bits/stdc++.h>
using namespace std;

vector<int> nums;

long long func(int target) {
    int left = 0;
    int right = nums.size() - 1;
    int ans = 0;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) {
            ans = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }

    // ans 为 0 时，说明 nums[0] >= target，左侧没有更接近的值
    if (ans == 0) {
        return abs(nums[0] - target);
    }

    return min((long long)abs(nums[ans] - target), (long long)abs(nums[ans - 1] - target));
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(NULL);

    int m, n;
    cin >> m >> n;
    nums.resize(m);
    for (int i = 0; i < m; i++) {
        cin >> nums[i];
    }
    sort(nums.begin(), nums.end());

    long long fi = 0; // 必须使用 long long 防溢出
    for (int i = 0; i < n; i++) {
        int target;
        cin >> target;
        if (target >= nums[m - 1]) {
            fi += (target - nums[m - 1]);
        } else if (target <= nums[0]) {
            fi += (nums[0] - target);
        } else {
            fi += func(target);
        }
    }

    cout << fi << "\n";
    return 0;
}
```
