# 二维区域和检索-矩阵不可变

## 题目：
给定一个二维矩阵matrix计算其子矩形范围内元素的总和
该子矩阵的左上角为 (row1, col1)右下角为 (row2, col2)

## 题目分析：
矩阵区域和检索问题使用二维前缀和

## 代码：
- CPP
``` 
class NumMatrix
{
    vector<vector<int>> prefix_num;
    NumMatrix(vector<vector<int>> nums)
    {
        int m=nums.size();
        int n=nums[0].size();
        prefix_num.assign(m+1,vector<int>(n+1,0));
        for(int i=0;i<m;i+=1)
        {
            for(int j=0;j<n;j+=1)
            {
                prefix_num[i+1][j+1]=prefix_num[i][j+1]+prefix_num[i+1][j]-prefix_num[i][j]+nums[i][j];
            }
        }
    }
    int rangeSum(int row1,int row2,int col1,int col2)
    {
        return (prefix_num[row2+1][col2+1]-prefix_num[row2+1][col1]-prefix_num[row1][col2+1]+prefix_num[row1][col1]);
    }
};
```
- PY
```
class NumMatrix:

    def __init__(self, matrix: list[list[int]]):
        if not matrix or not matrix[0]:
            return
        
        m, n = len(matrix), len(matrix[0])
        # 创建 (m + 1) x (n + 1) 的前缀和矩阵，全部初始化为 0
        self.prefix_num = [[0] * (n + 1) for _ in range(m + 1)]
        
        # 构建二维前缀和
        for i in range(m):
            for j in range(n):
                self.prefix_num[i + 1][j + 1] = (
                    self.prefix_num[i][j + 1] 
                    + self.prefix_num[i + 1][j] 
                    - self.prefix_num[i][j] 
                    + matrix[i][j]
                )

    def sumRegion(self, row1: int, col1: int, row2: int, col2: int) -> int:
        # 对应图中的 rangeSum 函数
        return (
            self.prefix_num[row2 + 1][col2 + 1]
            - self.prefix_num[row1][col2 + 1]
            - self.prefix_num[row2 + 1][col1]
            + self.prefix_num[row1][col1]
        )
```
