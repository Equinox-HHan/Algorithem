# 区域和检索-数组不可变

## 题目:
给定一个整数数组nums，计算索引left和right（包含left和right）之间的nums元素的和其中left<=right

## 题目分析：
计算数组某个闭区间的元素和如果使用遍历加数会超时适合使用前缀和解决
注意原始数组和前缀和数组的下标不对齐，建议前缀和数组整体右移一位

## 代码：

- PY
```
class NumArray:

    def __init__(self, nums: list[int]):
        # 建立长度为 len(nums) + 1 的前缀和数组
        # prefix_num[i] 表示 nums[0...i-1] 的和
        self.prefix_num = [0] * (len(nums) + 1)
        
        # 构建前缀和数组
        for i in range(len(nums)):
            self.prefix_num[i + 1] = self.prefix_num[i] + nums[i]

    def sumRange(self, left: int, right: int) -> int:
        # 对应图中的 getSum 函数
        # 核心公式：S[left...right] = prefix_num[right + 1] - prefix_num[left]
        return self.prefix_num[right + 1] - self.prefix_num[left]
```
