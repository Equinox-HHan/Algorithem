# 和为k的子数组

## 题目：
给你一个整数数组nums和一个整数k请你统计并返回该数组中和为k的子数组的个数
子数组是数组中元素的连续非空序列

## 题目分析：
前缀和变形`pre_sum[j]-pre_sum[i]=k`等价于`pre_sum[i]=pre_sum[j]-k`
从左到右滑动记录并使用单个变量维护前缀和
哈希表中记录的内容自然是满足题目要求的
一定要先更新count再更新哈希表（子数组不能为空）

## 代码：
- CPP
```
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int,int> Hash;
        int count=0,pre_sum=0;
        Hash[0]=1;
        for(int i=0;i<nums.size();i+=1)
        {
            pre_sum+=nums[i];          
            int left=pre_sum-k;
            if(Hash.count(left))
            {
                count+=Hash[left];
            }
            Hash[pre_sum]+=1;
        }
        return count;
    }
};
```
- PY
```
def func(nums,k):
    count,pre_sum=0
    Hash{0:1}
    for num in nums:
        pre_sum+=num
        if pre_sum-k in Hash:
            count+=Hash[pre_sum-k]
        Hash[pre_sum]=Hash.get(pre_sum,0)+1
    return count
```
