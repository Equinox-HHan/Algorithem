# 字符串的排列

## 题目：
给你两个字符串s1和s2判断s2是否包含s1的排列如果是返回true否则返回false
换句话说s1的排列之一是s2的子串

## 题目分析：
字串必须连续并且s1长度固定那么可以使用定长滑动窗口
排列问题不考虑顺序本质就是异位词问题

## 代码：
- CPP
```
bool func(string s1,string s2)
{
    if(s2.size()<s1.size())
    {
        return false;
    }

    vector<int> isExist(26,0);
    vector<int> count(26,0);
    for(int i=0;i<s1.size();i+=1)
    {
        count[s2[i]-'a']+=1;
        isExist[s1[i]-'a']+=1;
    }
    if(count==isExist)
    {
        return true;
    }
    for(int pos=1;pos<=s2.size()-s1.size();pos+=1)
    {
        count[s2[pos-1]-'a']-=1;
        count[s2[pos+s1.size()-1]-'a']+=1;
        if(count==isExist)
        {
            return true;
        }
    }
    return false;
}
```
