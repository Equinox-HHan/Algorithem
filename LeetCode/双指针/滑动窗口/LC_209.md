# 长度最小的子数组

## 题目：
给定一个含有 n 个正整数的数组和一个正整数 target 。
找出该数组中满足其总和大于等于 target 的长度最小的子数组并返回其长度
如果不存在符合条件的子数组返回0 

## 关键词：
1. **子数组（表示连续不中断）**
2. **最小长度**

## 题目分析：
这道题目适用滑动窗口求最小区间
1. 右指针移动时改变了什么状态（`count+=nums[right]`）
2. 什么情况下可以进入内循环（`count>=target`）
3. 左指针移动前要改变什么条件（`count-=nums[left]`）
4. 在什么位置更新全局答案：
>求最小值问题要在while内更新全局答案，并且放在左指针移动前
>while内是合法状况，在合法状体下求最小值并不断压缩

## 代码：
- CPP:
```
int func(vector<int> &nums,int target)
{
    int left=0,count=0;
    int ans=INT_MAX;
    for(int right=0;right<nums.size();right+=1)
    {
        count+=nums[right];
        while(count>=target)
        {
            ans=min(ans,right-left+1);
            count-=nums[left];
            left+=1;
        }
    }
    return ans==INT_MAX?0:ans;
}
```
- PY
```
def func(nums,target):
    left,count=0,0
    ans=float('inf')
    for right in range(len(nums)):
        count+=nums[right]
        while count>=target:
            ans=min(ans,right-left+1)
            count-=nums[left]
            left+=1
    return 0 if ans==float('inf') else ans
```
