# 两数之和-输入有序数组

## 题目：
给你一个下标从1开始的整数数组numbers该数组已按非递减顺序排列，找出相加之和等于target的两个数。
如果设这两个数分别是numbers[index1]和numbers[index2]，则1 <= index1 < index2<= numbers.length 。
以长度为2的整数数组[index1, index2]的形式返回这两个整数的下标 index1 和 index2。
你可以假设每个输入只对应唯一的答案 ，而且你不可以重复使用相同的元素。
你所设计的解决方案必须只使用常量级的额外空间。

## 题目分析：
数组是有弱序关系的则要使加和为定值可以采用对撞指针
并且`left<right`不能取等

## 代码：
- CPP
```
vector<int> func(vector<int> &nums,int target)
{
    int left=0,right=nums.size()-1;
    while(left<right)
    {
        int count=nums[left]+nums[right];
        if(count==target)
        {
            break;
        }
        else if(count<target)
        {
            left+=1;
        }
        else
        {
            right-=1;
        }
    }
    return {left+1，right+1};
}
```
- PY
```
def func(nums,target):
    left,right=0,len(nums)-1
    while left<right:
        ans=nums[left]+nums[right]
        if(ans==target):
            break
        elif ans<target:
            left+=1
        else:
            right-=1
    return [left+1,right+1]
```
