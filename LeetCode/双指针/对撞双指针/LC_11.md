# 盛水最多的容器

## 题目：
给定一个长度为n的整数数组height。有n条垂线第i条线的两个端点是 (i, 0) 和 (i, height[i]) 。
找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。
返回容器可以储存的最大水量。
![alt text](question_11.jpg)

## 题目分析：
由于每次向中间移动缩短宽度因此要使高度最高，木桶效应双指针每次移动高度较低的指针
而且在这种条件下`left<right`不能去等否则没有意义

## 数学证明：
核心表达式：`S(i,j)=(i-j)*min(nums[i],nums[j])`假设当前`nums[i]<=nums[j]`则移动左指针`i=i+1`
那么会排除集合`E={(i,k)|i<k<j}`由不等式`min(nums[i],num[k])<=nums[i]`结合条件`nums[i]<=nums[j]`
可以推导出`min(nums[i],nums[k])<=nums[j]`则被排除的部分不可能更大

## 代码：
- CPP
```
int func(vector<int> &nums)
{
    if(nums.size()<2)
    {
        return 0;
    }
    int left=0,right=nums.size()-1;
    int ans=0;
    while(left<right)
    {
        ans=max(ans,(right-left)*min(nums[left],nums[right]));
        if(nums[left]<=nums[right])
        {
            left+=1;
        }
        else
        {
            right-=1;
        }
    }
    return ans;
}
```

```
def func(nums: list[int]) ->int:
    if len(nums)<2:
        return 0
    ans,left,right=0,0,len(nums)-1
    while(left<right):
        ans=max(ans,(right-left)*min(nums[left],nums[right]))
        if nums[left]<=nums[right]:
            left+=1
        else:
            right-=1
    return ans
```
