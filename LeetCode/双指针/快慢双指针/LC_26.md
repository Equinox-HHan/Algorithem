# 删除有序数组中的重复项

## 题目：
给你一个的非严格第序排列的数组nums请你原地删除重复出现的元素，使每个元素只出现一次返回删除后数组的新长度。
元素的相对顺序应该保持一致 。然后返回 nums 中唯一元素的个数。
考虑nums的唯一元素的数量为k。去重后返回唯一元素的数量k
nums 的前 k 个元素应包含 排序后 的唯一数字。下标 k - 1 之后的剩余元素可以忽略。

## 关键词：
1. **有弱序关系**
2. **原地操作**
3. **保持相对顺序**

## 题目分析：
数组本身就是有弱序关系的可以使用快慢指针做覆盖处理
- 快指针搜索合法元素并且覆盖重复元素
- 慢指针维护合法区间的边界（`slow+1`是下一个覆盖位）

## 代码
- CPP
```
int removeDuplicates(vector<int>& nums)
{
    if(nums.size()==1)
    {
        return 1;
    }
    int slow=0,fast=1;
    for(fast;fast<nums.size();fast+=1)
    {
        if(nums[fast]!=nums[slow])
        {
            slow+=1;
            nums[slow]=nums[fast];
        }
    }
    return slow+1;
}
```
- PY
```
def func(nums):
    if not nums:
        return 0
    slow=0
    for fast in range(1:len(nums)):
        if nums[fast]!=nums[slow]:
            slow+=1
            nums[slow]=nums[fast]
    return slow+1
```
