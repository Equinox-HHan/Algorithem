# 移除元素

## 题目：
给你一个数组nums和一个值val，你需要原地移除所有数值等于val的元素
元素的顺序可能发生改变。然后返回nums中与val不同的元素的数量。

## 关键词：
1. **原地移除**

## 分析思路：
原地操作适用快慢双指针
1. 快指针寻找数值不为Val的元素准备覆盖
2. 慢指针负责维护边界（`slow+1`是下一个等待被覆盖位）

## 代码：
- CPP
```
int removeElement(vector<int>& nums, int val)
{
    if(nums.empty())
    {
        return 0;
    }
    int slow=0,fast=0;
    for(fast;fast<nums.size();fast+=1)
    {
        if(nums[fast]!=val)
        {
            nums[slow]=nums[fast];
            slow+=1;
        }
    }
    return slow;
}
``` 
- PY
```
def func(nums,val):
    if not nums:
        return 0
    slow=0
    for fast in range(len(nums)):
        if(nums[fast]!=val):
            nums[slow]=nums[fast]
            slow+=1
    return slow
```
