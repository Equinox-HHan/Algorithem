# 在排序数组中查找元素的第一个和最后一个位置

## 题目：
给你一个按照非递减顺序排列的整数数组nums和一个目标值target找出目标值在数组中的开始位置和结束位置。
如果数组中不存在目标值 target，返回 [-1, -1]。
你必须设计并实现时间复杂度为 O(log n) 的算法解决此问题

## 题目分析：
寻找大于等于目标值的首位置和寻找小于等于目标值的末位置的结合
关键就在于通过bool变量管理指针（把两个辅助函数合并到一起）

## 代码：
- CPP
```
vector<int> searchRange(vector<int>& nums, int target)
{
    int first=func(nums,target,0);
    int last=func(nums,target,1);
    return {first,last};
}
int func(vector<int> &nums,int target,bool flag)
//寻找左值0寻找右值1
{
int ans=-1;
    int left=0,right=nums.size()-1;
    while(left<=right)
    {
        int mid=left+(right-left)/2;
        if(nums[mid]==target)
        {
            if(!flag)
            {
                ans=mid;
                right=mid-1;                
            }
            else
            {
                ans=mid;
                left=mid+1;
            }
        }
        else if(nums[mid]<target)
        {
            left=mid+1;            
        }
        else
        {
            right=mid-1;
        }
    }
    return ans;
}
```
- PY
```
def searchRange(nums,target):
    first=func(nums,target,0)
    last=func(nums,target,1)
    return [first,last]

def func(nums,target,flag):
    left,right=0,len(nums)-1
    ans=-1
    while(left<=right):
        mid=left+(right-left)//2

        if nums[mid]==target:
            ans=mid
            if flag:
                left=mid+1
            else:
                right=mid-1
        elif nums[mid]>target:
            right=mid-1
        else:
            left=mid+1
    return ans
```
