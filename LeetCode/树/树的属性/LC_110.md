# 平衡二叉树

## 题目：
给定一个二叉树，判断它是否是 平衡二叉树  

## 分析：
平衡二叉树：左右子树高度差不超过1
那么还是需要求解左右子树的高度，适合用后序遍历求最大高度
剪枝优化：如果已经不平衡了提前返回-1，否则返回真实高度

## 代码：
- CPP
```
class Solution {
public:
    int help_func(TreeNode* root){
        if(!root){
            return 0;
        }
        int left=help_func(root->left);
        if(left==-1){
            return -1;
        }
        int right=help_func(root->right);
        if(right==-1){
            return -1;
        }
        if(abs(left-right)>1){
            return -1;
        }
        return max(left,right)+1;
    }
    bool isBalanced(TreeNode* root) {
        return help_func(root)==-1?0:1;
    }
};
```
- PY
```
from typing import Optional

class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        def get_height(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            
            left = get_height(node.left)
            if left == -1:
                return -1
            
            right = get_height(node.right)
            if right == -1:
                return -1
            
            if abs(left - right) > 1:
                return -1
            
            return max(left, right) + 1

        return get_height(root) != -1
```
