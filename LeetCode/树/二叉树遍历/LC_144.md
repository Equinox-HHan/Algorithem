# 二叉树的前序遍历

## 题目：
给你二叉树的根节点 root ，返回它节点值的 前序 遍历

## 分析：
前序遍历如果使用递归方法，只需要在处理左右子树之前完成对根的处理
使用非递归方法则用栈的结构，注意压栈顺序和处理顺序相反

## 代码：
- CPP
```
vector<int> preOrderTraversal(TreeNode *root){
    if(!root){
        return {};
    }
    vector<int> ans;
    stack<TreeNode*> s;
    s.push(root);
    while(!s.empty()){
        TreeNode *cur=s.top();
        s.pop();
        ans.push_back(cur->val);

        if(cur->right){
            s.push(cur->right);
        }
        if(cur->left){
            s.push(cur->left);
        }
    }
    return ans;
}
```
递归方法需要写辅助函数
- PY
```
def preOrderTraversal(root):
    if not root:
        return []

    ans = []
    stack = [root]

    while stack:
        node = stack.pop()
        ans.append(node.val)

        # 先压入右节点，再压入左节点（保证出栈时先访问左节点）
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)

    return ans  
```
