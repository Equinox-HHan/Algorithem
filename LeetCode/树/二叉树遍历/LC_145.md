# 二叉树的后序遍历

## 题目：
给你一棵二叉树的根节点 root ，返回其节点值的 后序遍历

## 分析：
后序遍历只需要在前序遍历的基础之上对压栈顺序调整即可

## 代码：
- CPP
```
vector<int> postOrderTraversal(TreeNode *root){
    if(!root){
        return {};
    }
    vector<int> ans;
    stack<TreeNode*> s;
    s.push(root);
    while(!s.empty()){
        TreeNode *cur=s.top();
        s.pop();
        ans.push_back(cur->val);

        if(cur->left){
            s.push(cur->left);
        }
        if(cur->right){
            s.push(cur->right);
        }
    }
    reverse(ans.begin(),ans.end());
    return ans;
}
```
