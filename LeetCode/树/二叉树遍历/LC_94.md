# 二叉树的中序遍历

## 题目：
给定一个二叉树的根节点 root ，返回 它的 中序 遍历

## 分析：
中序遍历顺序是左中右，所以根节点处理要在左子树全部完成之后

## 代码:
- CPP
```
vector<int> inOrderTraversal(TreeNode* root){
    if(!root){
        return {};
    }
    vector<int> ans;
    stack<TreeNode*> s;
    TreeNode *node=root;
    while(node||!s.empty()){
        while(node){
            s.push(node);
            node=node->left;
        }
        node=s.top();
        s.pop();
        ans.push_back(node->val);
        node=node->right;
    }
    return ans;
}
```
- PY
```
def inOrderTraversal(root):
    ans = []
    stack = []
    curr = root

    while curr or stack:
        # 一直向左深入并将节点压入栈
        while curr:
            stack.append(curr)
            curr = curr.left

        # 弹出栈顶节点并访问
        curr = stack.pop()
        ans.append(curr.val)

        # 转向右子树
        curr = curr.right

    return ans
```
