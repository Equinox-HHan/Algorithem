# 二叉树的层序遍历

## 题目：
给你二叉树的根节点 root 返回其节点值的层序遍历（即逐层地，从左到右访问所有节点）

## 分析：
层序遍历使用的数据结构是队列，每次处理一个节点就将左右子节点压入队列，自然按层从左到右展开
如何判断当前层已经处理完可以压入总答案：需要通过变量levelSize锁定

## 代码：
- CPP
```
vector<vector<int>> levelOrder(TreeNode* root){
    if(!root){
        return {};
    }
    queue<TreeNode*> q;
    vector<vector<int>> ans;
    vector<int> levelAns;
    int levelsize=0;
    q.push(root);
    while(!q.empty()){
        levelsize=q.size();
        while(levelsize--){
            TreeNode *node=q.front();
            q.pop();
            levelAns.push_back(node->val);
            if(node->left){
                q.push(node->left);
            }
            if(node->right){
                q.push(node->right);
            }
        }
        ans.push_back(levelAns);
        levelAns.clear();
    }
    return ans;
}
```
- PY
```
from collections import deque

def levelOrder(root):
    if not root:
        return []

    ans = []
    q = deque([root])

    while q:
        level_size = len(q)
        level_ans = []

        # 遍历当前层的每一个节点
        for _ in range(level_size):
            node = q.popleft()
            level_ans.append(node.val)

            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)

        ans.append(level_ans)

    return ans
```
