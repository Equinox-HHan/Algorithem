# 多数元素

## 题目：
给定一个大小为n的数组nums返回其中的多数元素。多数元素是指在数组中出现次数大于⌊ n/2 ⌋的元素
你可以假设数组是非空的，并且给定的数组总是存在多数元素

## 题目分析：
计数类型的题目可以使用哈希表：每回合更新哈希表计数并且选出最大值
对于众数永远存在的题目也可以使用摩尔投票法

## 代码：
- CPP
```
int func(vector<int> &nums){
    if(nums.size()==1){
        return nums[0];
    }
    unordered_map<int,int> Hashmap;
    for(int i=0;i<nums.size();i++){
        Hashmap[nums[i]]+=1;
    }
    int ans=0,count=INT_MAX;
    for(const auto& [key,value]:Hashmap){
        if(value>count){
            count=value;
            ans=key;
        }
    }
    return ans;
}
//摩尔投票法
int func(vector<int> &nums){
    if(nums.size()==1){
        return nums[0];
    }
    int ans=nums[0],count=0;
    for(int number:nums){
        if(count==0){
            ans=number;
            count=1;
        }
        count=(number==ans?count+1:count-1);
    }
    return ans;
}
```
- PY
```
def func(nums):
    if not nums:
        return None
    
    # 统计频率
    hashmap = {}
    for num in nums:
        hashmap[num] = hashmap.get(num, 0) + 1
        
    # max() 会根据 hashmap.get(k) 即 value 的大小比较，返回对应的 key
    return max(hashmap, key=hashmap.get)
```
