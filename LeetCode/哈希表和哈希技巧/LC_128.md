# 最长连续序列

## 题目：
给定一个未排序的整数数组 nums 找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度
请你设计并实现时间复杂度为 O(n) 的算法解决此问题

## 题目分析：
频繁查找元素并且存在重复元素要使用unordered_set
找最长序列要规避序列中间元素查找则要确定序列起点（去判断x-1是否存在）
只有确定是去起点才进入x+1,x+2....的循环

## 代码：
- CPP
```
int longestConsecutive(vector<int>& nums) {
        if(nums.size()==0){
            return 0;
        }
        int ans=-1;
        unordered_set<int> us(nums.begin(),nums.end());
        for(int x:us){
            if(!us.count(x-1)){
                int count=1;
                int cur_x=x+1;
                while(us.count(cur_x)){
                    count+=1;
                    cur_x+=1;
                }
                ans=max(count,ans);
            }
            continue;
        }
        return ans;
    }
```
