# 字母异位分词

## 题目：
给你一个字符串数组请你将 字母异位词 组合在一起可以按任意顺序返回结果列表

## 题目分析：
涉及到异位词可以使用哈希表：关键是键值对的设计
按照字符串排序后作为键，将所有异位词压入作为值的数组

## 代码：
- CPP：
```
vector<vector<string>> func(vector<string> &strs){
    vector<vector<string>> ans;
    unordered_map<string,vector<string>> um;
    for(int i=0;i<strs.size();i++){
        string s=strs[i];
        string key=s;
        sort(key.begin(),key.end());
        um[key].push_back(s);
    }
    for(const auto& [key,value]:um){
        ans.push_back(value);
    }
    return ans;
}
```
- PY
```
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        um = defaultdict(list)
        
        for s in strs:
            # 将字符串按字符排序后拼回字符串作为 key
            key = ''.join(sorted(s))
            um[key].append(s)
            
        # 返回哈希表中所有分组的值
        return list(um.values())
```
