# 缺失的第一个正数

## 题目：
给你一个未排序的整数数组 nums ，请你找出其中没有出现的最小的正整数
请你实现时间复杂度为 O(n) 并且只使用常数级别额外空间的解决方案

## 题目分析：
唯一的最优解是原地哈希：假设数组长度为n
1. 如果数组元素从1-n则返回n+1
2. 只要有非正数和重复数或者大于n的数则答案必定[1,n]
不需要处理负数和超范围大数只需要按照映射关系交换数字

## 代码：
- CPP
```
class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();

        // 1. 原地交换：将数字 x 放到下标 x - 1 的位置上
        for (int i = 0; i < n; ++i) {
            // 条件判断：
            // 1. nums[i] 在 [1, n] 范围内
            // 2. nums[i] 还没有到达它应该去的位置 (nums[i] != nums[nums[i] - 1])
            // 使用 while 是为了防止换过来的新元素也需要继续被交换到正确位置
            while (nums[i] > 0 && nums[i] <= n && nums[i] != nums[nums[i] - 1]) {
                swap(nums[i], nums[nums[i] - 1]);
            }
        }

        // 2. 检查哪个位置上的数字不符合 nums[i] == i + 1
        for (int i = 0; i < n; ++i) {
            if (nums[i] != i + 1) {
                return i + 1; // 找到了第一个缺失的正数
            }
        }

        // 3. 如果 1 到 n 都在正确位置上，说明缺失的是 n + 1
        return n + 1;
    }
};
```
- PY
```
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        n = len(nums)
        
        # 1. 原地交换
        for i in range(n):
            while 1 <= nums[i] <= n and nums[i] != nums[nums[i] - 1]:
                # Python 连续赋值交换时，先更新 nums[nums[i]-1] 避免 nums[i] 被覆盖
                correct_idx = nums[i] - 1
                nums[i], nums[correct_idx] = nums[correct_idx], nums[i]
                
        # 2. 检查缺失值
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
                
        # 3. 完美匹配，返回 n + 1
        return n + 1
```
