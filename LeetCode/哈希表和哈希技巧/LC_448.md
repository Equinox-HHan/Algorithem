# 找到所有数组中消失的数字

## 题目：
给你一个含n个整数的数组nums其中nums[i]在区间[1, n]内，
请你找出所有在[1, n]范围内但没有出现在nums中的数字，并以数组的形式返回结果

## 题目分析：
nums[i]在区间[1,n]之间则可以使用原地哈希
映射关系：将数字i映射到下标i-1

## 代码：
- CPP
```
vector<int> func(vector<int> &nums){
    vector<int> ans;
    for(int i=0;i<nums.size();i++){
        int x=abs(nums[i]);
        nums[x-1]=-abs(nums[x-1]);
    }
    for(int i=0;i<nums.size();i++){
        if(nums[i]>0){
            ans.push_back(i+1);
        }
    }
    return ans;
}
```
- PY
```
def findDisappearedNumbers(nums: list[int]) -> list[int]:
    # 1. 遍历数组，将数字 x 对应的下标 abs(x) - 1 处的元素标记为负数
    for num in nums:
        x = abs(num)
        # 使用 -abs() 确保无论该数字出现多少次，对应位置都保持为负数
        nums[x - 1] = -abs(nums[x - 1])
        
    # 2. 再次遍历数组，下标 i 处的元素仍为正数，说明 i + 1 从未出现过
    ans = []
    for i in range(len(nums)):
        if nums[i] > 0:
            ans.append(i + 1)
            
    return ans
```
