# 合并两个有序链表

## 题目：
将两个升序链表合并为一个新的 升序 链表并返回，新链表是通过拼接给定的两个链表的所有节点组成的。
![alt text](image.png)

## 题目分析：
尝试使用归并思路解决两个链表合并

## 代码：
- CPP：
```
ListNode *mergeList(ListNode *list1,ListNode *list2){
    ListNode dummy(0);
    ListNode *ptr1=list1,*ptr2=list2;
    ListNode *cur=&dummy;
    while(ptr1!=nullptr&&ptr2!=nullptr){
        if(ptr1->value<=ptr2->value){
            cur->next=ptr1;
            ptr1=ptr1->next;
        }
        else{
            cur->next=ptr2;
            ptr2=ptr2->next;
        }
        cur=cur->next;
    }
    cur->next=(ptr1==nullptr)?ptr2:ptr1;
    return dummy.next;
}
```
- PY
```
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def mergeList(list1: ListNode, list2: ListNode) -> ListNode:
    dummy = ListNode(0)
    cur = dummy
    ptr1, ptr2 = list1, list2

    while ptr1 and ptr2:
        if ptr1.val <= ptr2.val:
            cur.next = ptr1
            ptr1 = ptr1.next
        else:
            cur.next = ptr2
            ptr2 = ptr2.next
        cur = cur.next

    # 连接剩余未遍历完的链表部分
    cur.next = ptr2 if ptr1 is None else ptr1

    return dummy.next
```
