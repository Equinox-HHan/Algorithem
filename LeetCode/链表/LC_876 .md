# 链表的中间节点

## 题目：
给你单链表的头结点 head ，请你找出并返回链表的中间结点
如果有两个中间结点，则返回第二个中间结点

## 题目分析：
找中间节点是模板题目：注意找上节点还是下节点
关乎到while循环条件的严格性

## 代码：
- CPP
```
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        if(head->next==nullptr){
            return head;
        }
        ListNode *slow=head;
        ListNode *fast=head;
        while(fast!=nullptr&&fast->next!=nullptr){
            slow=slow->next;
            fast=fast->next->next;
        }
        return slow;
    }
};
``` 
- PY
```
def findMiddle(ListNode *head):
    fast,slow=head,head
    while fast!=None and fast.next!=None:
        fast=fast.next.next
        slow=slow.next
    return slow
```
