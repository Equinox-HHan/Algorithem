# 回文链表

## 题目：
给你一个单链表的头节点 head 请你判断该链表是否为回文链表；如果是返回 true ；否则返回 false

## 题目分析：
找到链表的中点（上中点）然后对前半段链表进行翻转进行比较
回文串就是从两边往中间遍历结果一样，当左右两侧遍历方向一致时说明一侧要整体反转

```
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val  # 若原结构体为 value 可替换为 self.value
        self.next = next


def reverseNode(head: ListNode, tail: ListNode) -> ListNode:
    cur, pre = head, None
    while cur != tail:
        temp = cur.next
        cur.next = pre
        pre = cur
        cur = temp
    return pre


def isPalindrome(head: ListNode) -> bool:
    if not head or not head.next:
        return True

    # 1. 统计链表长度
    slow = head
    len_of_list = 0
    while slow:
        slow = slow.next
        len_of_list += 1

    # 2. 快慢指针找中点
    slow, fast = head, head
    while fast.next and fast.next.next:
        fast = fast.next.next
        slow = slow.next

    # 3. 确定翻转区间并翻转前半部分
    tail = slow.next if len_of_list % 2 == 0 else slow
    new_head = reverseNode(head, tail)

    # 4. 对比前半部分（已翻转）与后半部分
    a = new_head
    b = slow.next
    while a and b:
        if a.val != b.val:
            return False
        a = a.next
        b = b.next

    return True
```
