# 合并k个升序列表

## 题目：
给你一个链表数组，每个链表都已经按升序排列
请你将所有链表合并到一个升序链表中，返回合并后的链表

## 题目分析：
最终返回的结果需要升序排列，并且每个子链表已经升序排列
可以考虑使用优先队列，每次将子链表的表头放入优先队列然后取最小值接入总链表

## 代码：
- CPP:
```
struct compareNode{
    bool operator()(ListNode *a,ListNode *b){
        return a->val>b->val;
    }
}
ListNode *mergeKLists(vector<ListNode*>& lists){
    priority_queue<ListNode*,vector<ListNode*>,compareNode> pq;
    for(const auto& node:lists){
        pq.push(node);
    }
    ListNode dummy(0);
    ListNode *cur=&dummy;
    while(!pq.empty()){
        ListNode *temp=pq.top();
        pq.pop()；
        cur->next=temp;
        cur=cur->next;
        if(temp->next!=nullptr){
            pq.push(temp->next);
        }
    }
    return dummy.next;
}

- PY
```
import heapq
from typing import List, Optional

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def mergeKLists(lists: List[Optional[ListNode]]) -> Optional[ListNode]:
    heap = []
    
    # 将所有非空链表的头节点压入小顶堆
    # 使用递增的 i 作为中间排序键，防止 val 相同时引发 ListNode 对象不可比的 TypeError
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))
            
    dummy = ListNode(0)
    cur = dummy
    idx = len(lists)
    
    while heap:
        val, _, temp = heapq.heappop(heap)
        cur.next = temp
        cur = cur.next
        
        if temp.next:
            heapq.heappush(heap, (temp.next.val, idx, temp.next))
            idx += 1
            
    return dummy.next
