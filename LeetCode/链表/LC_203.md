# 移除链表元素

## 题目：
给你一个链表的头节点 head 和一个整数 val 请你删除链表中所有满足 Node.val == val 的节点并返回新的头节点 

## 题目分析：
删除符合某种条件的链表节点会涉及到头节点，需要使用虚拟头节点

## 代码：
- CPP
```
ListNode *deleteNode(ListNode *head,int x){
    ListNode dummy(0);
    ListNode *cur=&dummy;
    cur->next=head;
    while(cur->next!=nullptr){
        if(cur->next->value==x){
            ListNode *temp=cur->next;
            cur->next=temp->next;
            delete temp;
        }
        else{
            cur=cur->next;
        }
    }
    return dummy.next;
}
```
- PY
```
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val  # 若之前节点使用的属性是 value，这里也可以写成 self.value
        self.next = next


def deleteNode(head: ListNode, x: int) -> ListNode:
    # 1. 创建虚拟头节点 (dummy node)
    dummy = ListNode(0)
    dummy.next = head
    
    cur = dummy
    
    # 2. 遍历链表判断下一个节点的值
    while cur.next:
        if cur.next.val == x:
            # 找到匹配节点，跳过该节点（Python 垃圾回收机制会自动释放废弃对象，无需像 C++ 一样 delete）
            cur.next = cur.next.next
        else:
            # 未匹配到，指针继续后移
            cur = cur.next
            
    return dummy.next
```
