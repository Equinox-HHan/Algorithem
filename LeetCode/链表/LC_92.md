# 反转链表

## 题目：
给你单链表的头指针 head 和两个整数 left 和 right ，其中 left <= right 请你反转从位置 left 到位置 right 的链表节点，返回 反转后的链表

## 题目分析：
头插法只需要遍历一遍：核心是要确定交换逻辑

## 代码：
- CPP
```
ListNode *reverseNode(ListNode *head,int left,int right){
    ListNode dummy(0);
    ListNode *pre=&dummy;
    pre->next=head;
    for(int i=0;i<left-1;i+=1){
        pre=pre->next;
    }
    ListNode *cur=pre->next;
    for(int i=0;i<right-left;i+=1){
        ListNode *temp=cur->next;
        cur->next=temp->next;
        temp->next=pre->next;
        pre->next=temp;
    }
    return dummy.next;
}
```
- PY
```
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    def reverseBetween(self, head: ListNode, left: int, right: int) -> ListNode:
        # 1. 建立 dummy 节点，处理 left=1 的边界情况
        dummy = ListNode(0)
        dummy.next = head
        pre = dummy
        
        # 2. 将 pre 指针移动到反转区域的前一个节点
        for _ in range(left - 1):
            pre = pre.next
            
        # 3. cur 指向反转区域的第一个节点（反转后它会变成尾节点）
        cur = pre.next
        
        # 4. 头插法核心循环 (执行 right - left 次)
        for _ in range(right - left):
            temp = cur.next             # 1. 抓取要头插的节点
            cur.next = temp.next        # 2. cur 跳过 temp，指向下一个节点
            temp.next = pre.next        # 3. temp 指向 pre 当前的下一个节点（关键！）
            pre.next = temp             # 4. pre 指向 temp，完成头插
            
        return dummy.next
```
