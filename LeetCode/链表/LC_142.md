# 环形链表II

## 题目：
给定一个链表的头节点head返回链表开始入环的第一个节点。 如果链表无环则返回 null 不允许修改 链表

## 题目分析：
先判断是否有环然后用快慢指针找入环节点

## 代码：
- CPP
```
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        if(head==nullptr||head->next==nullptr){
            return nullptr;
        }
        ListNode *slow=head;
        ListNode *fast=head;
        bool isCircle=false;
        while(fast!=nullptr&&fast->next!=nullptr){
            fast=fast->next->next;
            slow=slow->next;
            if(slow==fast){
                isCircle=true;
                break;
            }
        }
        if(isCircle){
            fast=head;
            while(fast!=slow){
                fast=fast->next;
                slow=slow->next;
            }
            return slow;
        }
        return nullptr;
    }
};
```
- PY
```
def detectCycle(head: ListNode) -> ListNode:
    if not head or not head.next:
        return None

    fast = slow = head
    is_circle = False

    while fast and fast.next:
        fast = fast.next.next
        slow = slow.next
        if slow == fast:
            is_circle = True
            break  # 必须跳出循环

    if is_circle:
        fast = head
        while fast != slow:
            fast = fast.next
            slow = slow.next
        return slow

    return None
```
