# Pow(x,n)

## 题目：
实现 pow(x, n) ，即计算 x 的整数 n 次幂函数。

## 思路：
快速幂的本质是二进制拆分，任意指数n都可以表示为二进制组合
`n=b_k*2^k+b_k-1*2^k-1+......+b_1*2^1+b_0*2^0`根据指数相加底数相乘原理可得
`x^n=x^(b_k*2^k)*x^(b_k-1*2^k-1)*......*x^(b_0*2^0)`那么只需计算底数`b=1`的项并求求积

## 实现细节：
1. 一定要注意数据类型和整数溢出的问题
2. 要注意指数统一转化为整数

## 代码：
- CPP:
```
double func(double x,int n)
{
    if(x==0)
    {
        return 0;
    }
    double base=x;
    long long power=n;
    if(power<0)
    {
        power=-power;
        base=1/base;
    }

    double result=1;
    while(power!=0)
    {
        if(power%2==1)
        {
            power-=1;
            result=base*result;
        }
        power=power>>1;
        base=base*base;
    }
    return result;
}
```
