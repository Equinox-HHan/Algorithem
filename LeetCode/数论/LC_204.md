# 计数质数：

## 题目：
给定整数 n ，返回 所有小于非负整数 n 的质数的数量 

## 思路：
埃氏筛：任何质数的倍数都一定是和数

## 优化和细节：
1. 一定要先对n做特判，否则会造成数组越界
2. 外层循环边界`i*i<n`
3. 内层循环从`j=i*i`开始计算`j+=i`

## 代码：
- CPP
```int func(int n)
{
    if(n<=2)
    {
        return 0;
    }
    vector<bool> isPrime(n,true);
    isPrime[0]=false;
    isPrime[1]=false;
    int ans=0;
    for(int i=2;i*i<n;i++)
    {
        if(isPrime[i])
        {
            for(int j=i*i;j<n;j+=i)
            {
                isPrime[j]=false;
            }
        }
    }
    for(int i=0;i<n;i++)
    {
        if(isPrime[i])
        {
            ans+=1;
        }
    }
    return ans;
}
```
- PY
```
def func(number: int) ->int:
    if number<=2:
        return 0
    isPrime=[True]*n
    isPrime[0]=false
    isPrime[1]=false
    i=2
    while i*i<number:
        if isPrime[i]:
            for j in range(i*i,n,i):
                isPrime[j]=false
        i+=1
    return sum(isPrime)
```
